# SHUGE DAILY · 鼠哥晨间简报

一个面向长期积累的每日深度简报阅读器，作为 **鼠哥星系** 的独立内容产品发布在 GitHub Pages。

## 访问

- 在线：`/daily-brief/`
- 数据：`daily-brief/data/YYYY-MM-DD.json`
- 索引：`daily-brief/data/manifest.json`

## 信息结构

每期默认包含：

- 核心 10 条：AI / Agent、芯片与硬件、机器人、科学工程、科技产业、大学学习与 Wildcard
- 跨领域 8 条：政治 ×2、艺术、生物、教育、历史、金融、生态
- 18 条之后的 3 道跨领域思考题
- Project Scout：5 个项目候选 + 横向比较题
- 科技人物：1 位人物的经历、失败、约束与思考题
- 3–5 个今日信号 + 最多 2 个深挖主题

## 前端原则

- Progressive disclosure：标题与摘要优先，背景 / 意义 / 影响按需展开
- 阅读优先：弱化导航、强化正文，不复制星系主页的像素视觉
- Mobile first：iPhone 安全区、底部导航、归档抽屉
- 全局搜索：支持按事件、人物、项目和关键词检索全部归档
- 日 / 夜主题与“扫描 / 深度阅读”密度切换
- 尊重 `prefers-reduced-motion`
- 静态站点、零构建步骤，降低长期维护成本

## 每日归档方式

新增一天时只需要：

1. 新增 `data/YYYY-MM-DD.json`
2. 在 `data/manifest.json` 顶部增加该日期
3. 保留来源链接、事实边界和不确定性
4. 不修改前端模板，除非数据 schema 确实发生变化

这使历史简报可以长期积累，而不会随着天数增加把单个 HTML 文件变成不可维护的大文件。

## 质量规则

- 不为了凑数收录低价值新闻
- 新闻发生时间与报道时间分开
- 政治保持中立，区分事实 / 各方主张 / 分析
- 医学、生物研究严格区分基础研究与临床结论
- 金融不做荐股与买卖指令
- 项目候选先 Project Scout，不自动升级为开发任务
- 旧简报若需要回填，先重新核对来源再进入正式归档

## 技术

原生 HTML + CSS + JavaScript + JSON，直接由 GitHub Pages 托管。
