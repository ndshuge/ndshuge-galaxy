# GameVerse Vision — screenshot-led independent web launcher
Date: 2026-10-29. Intended audience: game players on macOS/Windows browsers and iPhone.
Source visual: two user-supplied desktop/mobile GameVerse images. Exact visual hierarchy: alpine wallpaper, translucent 3-column window (left 240/right 300), large art-led hero, progress cards and library shelf; on mobile brand header, segmented top tabs, scrollable hero and horizontal shelves plus fixed frosted bottom dock.
Function: carousel, library navigation/filter/search, persistent favorites, information modal, links to actual 16 browser games. Commercial AAA artworks are display-only; CTAs must say "查看游戏" / "Steam 商店", never misrepresent them as web-playable.
Options: A overwrite existing gameverse (rejected); B standalone new little-works/gameverse-vision/ with catalog entry (chosen); C new domain (unnecessary).
Site controls: responsive 320/390/768/1440; keyboard, Escape, reduced motion, safe areas. Liquid Glass uses frosted layered navigation and purposeful optical highlights with fallback, not native SwiftUI material claims.
Preserve existing gameverse, arcade-library and every other catalog item. Non-destructive isolated worktree publishing with fresh main.
