# 星系与艺术作品的素材来源

SHUGE GALAXY 包含原生 Canvas、静态页面、生成艺术实验与部分 WebGL 模型文件。作品虽然公开可访问，但不代表所有文件已经统一开源授权。

## 当前清点

| 路径 | 类型 | 待确认 |
| --- | --- | --- |
| `index.html` | 像素风星系入口 | 确认原创代码和所用字体来源 |
| `art/gravity-choir/models/gravity-choir.glb` | 3D 模型，约 1.9 MB | 模型来源、制作记录、许可与可再分发范围 |
| `art/` 其他作品 | 可视化与交互实验 | 逐项确认纹理、音乐、模型、字体的第三方授权 |
| `xian/index.html` | 独立交互作品，文件较大 | 复查是否嵌入了受限图片或其他资源 |

## 后续要求

- 素材登记：文件、创作者、来源链接、版权/许可证、允许的使用方式。
- 自创素材和第三方素材分别声明许可；无法确认许可的素材不应承诺允许商用。
- 开源许可证应在素材清点后按实际版权归属决定，不能盲目覆盖整个作品集。
