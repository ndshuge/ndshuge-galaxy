# LIMINAL · 引力边界 — Credits

## 创作方式
原创程序化宇宙艺术装置，基于 WebGL 2 / GLSL 和 Web Audio 构建；不依赖外部运行时、图片、字体、模型或在线 API。所有画面为美术化近似，不能用于天文学测量或广义相对论的数值研究。

## 设计与技术参考
- Eric Bruneton, [A Real-time High-quality Black Hole Viewer](https://github.com/ebruneton/black_hole_shader) — 黑洞实时可视化研究参考；本项目不包含其源码和预计算数据。
- [Scenes3D / black-hole](https://github.com/Scenes3D/black-hole) — 吸积盘冷暖层次、前后景构图参考；本作采用独立 GLSL 实现。
- [VoltAgent / awesome-design-md](https://github.com/VoltAgent/awesome-design-md/tree/main/design-md/apple) — 全幅主视觉、低界面密度参考；不复制第三方品牌素材。

## 音频与交互
声音由 Web Audio 在用户主动点击后合成，不含外部音频素材。拖动旋转、滚轮/双指缩放，1/2/3 切换章节，空格暂停，H 隐藏界面，方向键改变视角与距离。留影会把当前画面另存为 PNG。
