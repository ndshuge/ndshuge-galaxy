# Habit Flow · design decisions and release verification

## Scope and product
Habit Flow is a static, dependency-free daily habit tracker in `little-works/habit-flow/`. The key user job is to complete a habit with one tap on opening the app. The data model stores habits and date-keyed completions in the current browser's localStorage, with local JSON export/import. There is no account, telemetry or cross-device sync.

## Implementation mapping
- `index.html`: semantic header, today/review sections, 44px-adjacent touch controls, native accessible dialogs; back link to `../`.
- `style.css`: offwhite/sage surfaces, layered ring and restrained overview, persistent mobile dock, button/segmented transitions, focus-visible + motion/transparency preferences.
- `app.js`: date-local YYYY-MM-DD keys (not UTC), no invented sample completions, computed progress and history, backfill from month calendar, edit/delete confirmation, JSON import/export validation, text escaping.
