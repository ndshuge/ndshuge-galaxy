# 鼠哥 · 个人主页（小东西里的独立候选版）

本作品位于 [鼠哥星系小东西](../) 的子目录。它是独立的、可以单独打开的个人主页设计试验，不会覆盖既有的 `shuge-little-universe`。

本站使用已经公开的作品真实截图展示六个项目：环的另一边、知序 AI 学院、鼠哥游戏厅、山河为证、晴间、小作品星系。首页三个按钮可切换精选作品。没有后端、追踪、账号或用户输入数据存储。

详细的设计来源、Taste-Skill + Designeer 实际执行记录、图片归属说明，请阅读 [DESIGN_SOURCES.md](DESIGN_SOURCES.md)。测试通过并不代表人类审美验收已经完成。
