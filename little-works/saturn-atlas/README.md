# 环的另一边 / The Other Side of Saturn

位于 [鼠哥星系「小东西」](../) 的独立天文科普展品。

- **真实图像：** 2013-07-19 NASA 卡西尼号土星背光拼接图（NASA/JPL-Caltech/SSI，PIA17172）。
- **交互一：** 0–90° 改变观察土星环的视线仰角，体验环由“几乎一条线”变为椭圆乃至圆形的投影过程（示意，非轨道物理模拟）。
- **交互二：** 比较太阳光抵达地球、火星、木星、土星所需的平均分钟数（估算）。
- **架构：** 纯 HTML/CSS/Canvas/JavaScript，无运行时依赖、无第三方追踪、无后端与 API Key。深空真实照片已本地打包为 WebP。
- **验证：** 实际多视口 Edge/Playwright 测试后发布。设计过程与来源记录见 [DESIGN_SOURCES.md](./DESIGN_SOURCES.md)。
