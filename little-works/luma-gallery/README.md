# 光屿 LUMA · 私人照片画廊

无需服务器或账户的静态网页照片收藏应用。入口位于「小东西」的 \`little-works/luma-gallery/\`。

## 功能
- 本地批量导入 JPEG、PNG、WebP、GIF、AVIF、BMP（单张最大 70 MB），浏览器保留原始照片，额外生成 WebP 缩略图。
- 自定义分类、照片重命名、搜索、收藏，沉浸式原图浏览（键盘左右方向键、触摸滑动）。
- 450ms 长按呼出快捷菜单；按住期间提供持续视觉反馈，位移和取消会中断；也提供显式「···」菜单及 Shift+F10 键盘入口。
- 基于 IndexedDB 本地保存；完整原图 JSON 备份和恢复；删除前要求确认。

## 隐私与数据
网站不包含任何个人照片，也不使用后端上传。不同浏览器与设备不能同步。清理浏览器网站数据可能造成永久丢失。JSON 备份包含未加密的原始照片，不应公开分享；大规模照片的备份文件可能占用大量内存。

## 视觉与测试
依据 Apple Web Design 的信息架构、材质、动效和 QA 规范，结合 Taste-Skill 对排版密度与视觉克制的方向性方法；Designeer 灵感索引在本轮不可访问，未照搬组件。照片为主要内容，暖白编辑式首页与深色沉浸阅览对比。悬浮工具采用 L1 透明模糊和高光材质，有 L0 减少透明度降级，不声称已实现 L2 光学折射。CSS 弹性曲线配合可中断长按反馈，并尊重 prefers-reduced-motion。

本地在 Chromium CDP 自动化中完成空库、上传、收藏、分类、搜索、长按、取消态、原图查看、持久化、导出、删除及恢复，并于 320 / 390 / 768 / 1440px 检查响应式和水平溢出。未进行真实 iPhone Safari 手势测试。
